# Models and condition tables

This directory contains model snapshots and condition tables already present in the FluTOr repository.

For a reproducible experiment, record:

- model/database source;
- exact release/version;
- retrieval date;
- any manual preprocessing;
- exact repository commit;
- file checksum;
- condition-table version.

The maintained API prefers reaction IDs over bare positional indices where practical because row numbers are only meaningful for one exact model snapshot.
